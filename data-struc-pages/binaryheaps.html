Learning: Binary Heaps

Prerequisite Knowledge

This demonstration expects a reasonable understanding of Binary Trees

What is a Binary Heap?

Binary Heaps are deliniated by the folowing properities:

  • They are a binary tree (tree with each node having at most 2 children)
  • The binary tree is complete (Nodes are added from left to right)
  • It is heap-ordered: either max-heap or min-heap
    • Max-Heap: all children of a node are smaller than the current node
    • Min-Heap: all children of a node are greater than the current node
  • Height of this tree is log_2(n)

What are the Operations of a Binary Heap?

  • Insertion: uses a 'swim-up' method.
    • This method inserts a Node to the left most open child in the Tree.
    • This Node will then move up if its value is greater (max-heap) or lesser (min-heap) than the parent.
    • The recently inserted Node will continue to move up (siwm-up) until its value is no longer greater/lesser than the value of its parent.
  • Get Max/Min: uses a 'sink-down' method
    • For Binary Heaps, getting the max (max-heap) or min (min-heap) will result in deleting the max/min value from the heap. As such this also describes deletion from a Binary Heap
    • Swap the right-most, lowest element and the Root element
    • Return and delete the previous Root element (the max/min value) and the Node that was recently swapped
    • Sink the top-most element down, swapping with the children that is lesser(max)/greater(min) than the top-most element

How to Implement a Binary Heap

To implement a Binary Heap, arrays are used. This can be done since binary heaps most be complete. This property allows for the creation of a matematical equation to cacluate the index of the left and right child of some value in the array.

Using some index i, you can calculate the left child's index, right child's index and parent's index within the array using the value of i.

  • Left Child Calculation: 2i + 1
  • Right Child Calculation: 2i + 2
  • Parent Calculation: max(floor((i - 1) / 2), 0)
