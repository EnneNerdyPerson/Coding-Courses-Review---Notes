Learning: Linked Lists

What is a Linked List?

Linked Lists are a dynamic data structure with a multitude of uses. Unlike Array Lists, they don't use arrays but rather store new information as it is added. This is done through the creation of Nodes (which are implemented differently in different programming languages). This Node is made up of (at minimum) two important pieces of information, the data being stored, and the next Node in the Linked List.

NULL is used as an indicator that the Link List has ended. In this visual, each Node knows only the next Node in the list. head knowns that node2 is next but node2 doesn't know head is even in the list in the first place.

You can think of Linked Lists as a long chain of nodes, linked together through each Node knowing the next Node in the list. This is the simplest form of Linked List. Linked Lists can have links to both the Node before and after them and depending on the information that is being kept track of, Linked List can 'transform' into other data structures!

Types of Linked Lists

Singly Linked List

The simplest form of a Linked List. A Node (or list item) only links to the next Node in the list (Figure 1). However this means that you can only traverse through the list forwards and not backwards.

NULL

Doubly Linked List

The next iteration of a Linked Lists. A Node (or list item) links to both the next Node and the previous Node in the list. This allows for someone to traverse the list both forwards and backwards rather than only forwards.

NULL

Circularly Linked List

The last item in the list points to the beginning of the list. Rather than the last item pointing to NULL, the list repeats back at the beginning, allowing for some additional flexibility in traversing and utilizing the list.

How to make a Linked List?

Linked Lists require the creation of both a Node and a Linked List. The Linked List will utilize the Node in it's creation. Remember, how the Node is built also affects the abilities of the Linked List.

Node Class

  • Value/Data: the item stored within the Node
  • Next: the next node in the list
  • Previous (optional): the previous node in the list
    • This is only when creating a doubly linked list

Linked List Class: Fields

  • Head: the beginning Node in the Linked List
  • Size: the number of items/Nodes are in the Linked List
  • Tail (optional): the last Node in the Linked List
    • Keeping track of the tail/last Node can decrease insertion time depending on implementation and usage but a fully functional Linked List doesn't require keeping track of a tail

Linked List Class: Methods

  • Add Item/Value: add a new item to the list
    • Insertion can happen at the beginning, end, or middle of the list.
  • Get Item: get an item from the Linked List
    • This can have multiple different methods, depending on what purpose the Linked List is being used for.
    • This can be retrieved by the index of the element or retrieving the first/last item.
  • Delete: remove some item from a Linked List
    • One of the benefits of Linked Lists is that deletion of an item in the middle of the list doesn't require moving all elements in the Linked List over like you might need to do for Array Lists.

How to Insert/Delete Items Into a Linked List?

Insertion

  • Insertion Anywhere:
    1. Walk through the Linked List to find the Node that will point to the new Node being added, the 'before' Node.
      • It is recommended to use a while loop to walk through a Linked List.
      • Be careful of how you keep track of where you are in the list. If you aren't careful, you might add your Node later in the list than you prefer.
    2. Once this 'before' Node is found, save its next Node, our 'after' Node (the Node that will be after the new Node).
    3. Update the next value of the 'before' Node to our new Node.
    4. Update the next value of our new Node to the 'after' Node we saved earlier
  • Beginning Insertion: Have a new Node point to the current Head. Have Head point to new node
  • End Insertion: If keeping track of tail, use a similar method to beginning insertion. If not keeping track of the tail, you will need to iterate to the end of the list to add the new Node to the end

Deletion

  • Deletion Anywhere:
    1. Walk through the Linked List to the Node before the to-be-deleted Node.
    2. Once this 'before' Node is found, save the Node to be deleted, the 'before' Node's next Node.
    3. After that, save the Node after the Node to be deleted as this 'after' Node needs to be moved after the 'before' Node.
    4. Update the next value of the 'before' Node to the 'after' Node.
    5. For best practice, update the next value of our to-be-deleted Node to NULL.
      • This avoids any accidental changes to the rest of the list, especially if this to-be-deleted Node may be returned or reused in some way
  • Beginning Deletion: Save head to a temporary variable. Update the head of the Linked List to the next value of the temporary variable.
  • End Deletion: If it is a singly linked list or not keeping track of the tail of the list, you will need to iterate to the end of the list before using a similar method to Deletion Anywhere.

insert(value, index) { //assume insertion anywhere
  current ← head
  for i → index - 1 and current != null
    current ← current.next
  if current != null
    current.next ← new Node(value)
}

delete(index) { //assume deletion at index
  current ← head
  for i → index - 1 and current != null
    current ← current.next
  if current != null and current.next != null
    current.next ← current.next.next
}
