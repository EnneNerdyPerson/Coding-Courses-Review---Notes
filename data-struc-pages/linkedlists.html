Learning: Linked Lists

What is a Linked List?

Linked Lists are a dynamic datastructure with a multitude of uses. Unlike ArrayLists, they don't use arrays but rather create something called a Node. This Node is made up of at least two important peices of information, the data being stored, and the next Node in the Linked List

Linked Lists can have links to both the Node before and after them and depending on the information that is being kept track of, Linked List can 'transform' into other data structures!

Types of Linked Lists

Singly Linked List

A Node (or list item) only links to the next Node in the list (Figure 1). However this means that you can only traverse through the list forwards and not backwards.

NULL

Doubly Linked List

A Node (or list item) links to both the next Node and the previous Node in the list. This allows for someone to traverse the list both forwards and backwards rather than only forwards.

NULL

Circular Linked List

The list item in the list points to the beginning of the list. Rather than the last item pointing to NULL, the list repeats back at the beginning, allowing for some addition flexibility.

How to make a Linked List?

Linked Lists require the create of both a Node and a Linked List class. The Linked List class will utilize the Node class in it's creation. Remember, how the Node is built also effects the abilities of the Linked List.

Node Class

  • Value/Data: the item stored within the Node
  • Next: the next node in the list
  • Previous (optional): the previous node in the list
    • This is only when creating a doubly linked list

Linked List Class: Feilds

  • Head: the begginning Node in the Linked List
  • Size: the number of items/Nodes are in the Linked List
  • Tail (optional): the last Node in the Linked List
    • Keeping track of the tail/last Node can decrease insertion time depending on implementation and usage but a fully functional Linked List doesn't require keeping track of a tail

Linked List Class: Methods

  • Add Item/Value: add a new item to the list
    • This requires the creation of a new Node and insertion of that Node in the correct place in the list. Also increase size of Linked List
    • Insertion can happen at the beginning, end, or middle of list.
  • Get Item: get an item from the Linked List
    • This can have multiple different methods, depending on what purpose the Linked List is being used for.
    • This can be retrieved by the index of the element or retrieving the first/last item.
  • Delete: remove some item from a Linked List
    • One of the benefits of Linked Lists is that deletion of an item in the middle of the list doesn't require moving all elements in the Linked List over like you might need to do for Array Lists.
    • However, deletion is dependent on what is being kept track of, what part of the list is being deleted and more. In the best case, deletion is faster than Array Lists and in the worst case, it is the same as Array Lists.

How to Insert Items Into a Linked List?

  • Insertion Anywhere:
    1. Walk through the Linked List to the desired section of the list. (It is recommended to use a while loop to walk through a Linked List). Make sure to keep track of the Node that will be before the new Node as it's next value needs to be updated.
    2. Once this 'before' Node is found, save it's next Node, the Node that will be after the new Node.
    3. Update the next value of the 'before' Node to our new Node.
    4. Update the next value of our new Node to the 'after' Node we saved earlier
  • Beginning Insertion: Have new Node point to current Head. Have Head point to new node
  • End Insertion: If keeping track of tail, use similar method to beginning insertion. If not keeping track of the tail, you will need to iterate to the end of the list to add the new Node to the end

  current ← head
  for i → index - 1 and current != null
    current ← current.next
  if current != null
    current.next ← new Node(value)
}

delete(index) { //assume deletion at index
  current ← head
  for i → index - 1 and current != null
    current ← current.next
  if current != null and current.next != null
    current.next ← current.next.next
}
