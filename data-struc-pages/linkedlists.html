Learning: Linked Lists

Prerequisite Knowledge

This demonstration expects a reasonable understanding of Java classes and methods, and C structs.

What is a LinkedList?

LinkedLists are a dynamic datastructure with a multitude of uses. Unlike ArrayLists, they don't use arrays but rather create something called a Node. This Node is made up of at least two important peices of information, the data being stored, and the next Node in the LinkedList

data1
data2
data3
data4

NULL

The above LinkedList holds 4 items. The first item in the list has the value data1. You can think of LinkedLists as a long chain of nodes, linked together through knowing the next item in the list. This is the simplest form of a LinkedList. LinkedLists can have links to both the Node before and after them and depending on the information that is being kept track of, LinkedList can 'transform' into other data structures!

Terminology

  • Singly Linked List: a Node (or list item) only links to the next Node in the list (Figure 1)
  • Doubly Linked List: a Node (or list item) links to both the next Node and the previous Node in the list
    • This allows for someone to traverse the list both forwards and backwards rather than only forwards
  • Circular LinkedList: the list item in the list points to the beginning of the list.
    • Rather than the last item pointing to NULL, the list repeats back at the beginning, allowing for some addition flexibility.

How to make a LinkedList?

LinkedLists require the create of both a Node and a LinkedList class. The LinkedList class will utilize the Node class in it's creation. Remember, how the Node is built also effects the abilities of the LinkedList.

Node Class

  • Value/Data: the item stored within the Node
  • Next: the next node in the list
  • Previous (optional): the previous node in the list
    • This is only when creating a doubly linked list

LinkedList Class: Feilds

  • Head: the begginning Node in the LinkedList
  • Size: the number of items/Nodes are in the LinkedList
  • Tail (optional): the last Node in the LinkedList
    • Keeping track of the tail/last Node can decrease insertion time depending on implementation and usage but a fully functional LinkedList doesn't require keeping track of a tail

LinkedList Class: Methods

  • Add Item/Value: add a new item to the list
    • This requires the creation of a new Node and insertion of that Node in the correct place in the list. Also increase size of LinkedList
    • Insertion can happen at the beginning, end, or middle of list.
      • Insertion Anywhere:
        1. Walk through the LinkedList to the desired section of the list. (It is recommended to use a while loop to walk through a LinkedList). Make sure to keep track of the Node that will be before the new Node as it's next value needs to be updated.
        2. Once this 'before' Node is found, save it's next Node, the Node that will be after the new Node.
        3. Update the next value of the 'before' Node to our new Node.
        4. Update the next value of our new Node to the 'after' Node we saved earlier
      • Beginning Insertion: Have new Node point to current Head. Have Head point to new node
      • End Insertion: If keeping track of tail, use similar method to beginning insertion. If not keeping track of the tail, you will need to iterate to the end of the list to add the new Node to the end
  • Get Item: get an item from the LinkedList
    • This can have multiple different methods, depending on what purpose the LinkedList is being used for.
  • Get Size: get the size of the LinkedList
