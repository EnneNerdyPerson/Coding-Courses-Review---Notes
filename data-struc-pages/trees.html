Learning: Trees & Binary Search Trees

What is a Tree?

This is a dynamic data structure which is defined by having a 'root' node that is used to access the rest of the tree. Similar to a Linked List, Trees use Nodes in there creation. However, for Trees are non-linear, allows for uses outside of those for LinkedLists. This non-linearity happens as each Node in a tree can have multiple children, unlike LinkedLists which have at most a 'next' and 'previous' connection.

Terminology

  • Root: the Node which the Tree uses to access all other Nodes inside the Tree
  • Parent and Child: in this case, the children of a Node are the Nodes that some parent Node points to.
    • The parent of some Node called node1 is the Node that points to node1
    • The children of some Node called node3 is the Nodes that node3 points to
  • Leaf Node: the Nodes with no children are Leaf Nodes
  • Internal Node: any node that is not a Leaf Node is an Internal Node
  • Non-linear: poltting out a Tree will NOT result in a line

What is a Binary Tree?

Binary Trees, like the name implies are a type of Tree. However, there are some restrictions/properities that Binary Trees have that regular Trees do not. In additional to the properities of Trees, every Node in a Binary Tree have at most two (<=2) children. These children are often labels as left and right.

What is a Binary Search Tree?

Similiar to how all squares are recentangles but not all rectangles are squares, all Binary Trees are Trees but not all Trees are Binary Trees. What determines if a Tree is a Binary Tree or not, is if a Tree has at most two (0, 1, or 2) child Nodes.

A Binary Search Tree (BST) is a specical type of Binary Tree. The search in its name highlights this additional sepcification. At any Node x in the BST, all values stored in Nodes to the left of the Node x are smaller than the value stored at Node x. Additionally all values stored in Nodes to the right of Node x are greater than the value stored at Node x.

Binary Tree Terminology

Full Binary Tree

Every node other than the leaf nodes has two children.

Balanced Binary Tree

The path from the Root node to each NULL value is the same length

Complete Binary Tree

Every level, except the bottom level is completely filled where the last level has nodes that are as far left as possible
