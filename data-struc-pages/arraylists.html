Learning: Array Lists

Prerequisite Knowledge

Arrays are a fundemental part of understanding ArrayLists. This demonstration also expects a reasonable understanding of Java classes and methods, and C structs.

What is an Array List?

First, we must understand what an array is. Arrays are a basic datastructure common in most programming languages. However, they are limited as for programming languages like Java and C/C++, the size of an array is immultible (unchanging). This can often limit how arrays can be used. To still utilize the many strengths of arrays while allowing for the benefits of a dynamic data structure, Array Lists were created.

Java: int[] numArray = new int[10];

C/C++: int numArray[10];

Array Lists make use of arrays as a data structure but allow for dynamic sizing. They are useful where there is no clear size limit to the number of elements that may be added.

How to make an ArrayList?

ArrayLists require the following information:

Feilds

  • Array - this is where information will be stored
    • The type of this array should be the type of items you want to store
  • Size of ArrayList - this is the number of items that have been added to the array
  • Capacity - this is the maximum number of items the ArrayList can hold
    • This doesn't need to explicitly have an assigned variable if you can easily in O(1) time get the length of the Array

Methods

  • Add Item - add an item to the ArrayList
  • Resize/Reallocate - when capacity is met, increase the size of the array
    • There are multiple methodologies on how size should be increased.
      • Ex: Increase by N. increase by some set amount each time
      • Ex: Doubling. double the size of the array each time
    • However, these increase methods come with some cost considerations.
      • Increase by N my be too slow when lots of elements are added to the array and many cause several calls to the Resize/Reallocate method, resulting in inefficency.
      • Doubling can lead to a substantial amount of wasted space, espcially as the size of the array grows incredbily large
