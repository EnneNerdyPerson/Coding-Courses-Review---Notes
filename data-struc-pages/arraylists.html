Learning: Array Lists

What is an Array List?

First, we must understand what an array is. Arrays are a basic data structure common in most programming languages. However, a common limitation of arrays is the fact they are immutable (they do not change in size). This is true for arrays in programming languages like Java and C/C++ and NumPy arrays in Python. The unchanging nature of arrays can limit its uses. To still utilize the many strengths of arrays while allowing for the benefits of a dynamic data structure, Array Lists were created.

How to make an Array List?

Array Lists use arrays to store their data but to make it dynamic, every time the array is full, a new array of a larger size is created. The information from the smaller array is thus moved into the new larger array. This resizing and re-allocation process is fundamental to Array Lists as a data structure.

Variables

  • Array - this is where information will be stored
    • If it's a typed language, the type of this array should be the data type of the items you want to store
  • Size - this is the number of items that have been added to the array
    • This variable is also used to add or remove items to/from the ArrayList

Methods

  • Add Item - add an item to the ArrayList using the Size variable as an index for the array
  • Resize/Reallocate - when capacity is met, increase the size of the array
    • There are multiple methodologies on how size should be increased: increase capacity by n, double capacity, etc...

How to Deal with Resizing/Reallocating

Double Capacity

  • When the array is full, doubling the size of the array ensures that there is a significant amount of time before the array fills up once again.
  • However, doubling can lead to a substantial amount of wasted space, especially as the size of the array grows incredibly large.

Increase Capacity by n

  • Increasing the size by some number n, the array can contain more information but will likely reduce the wasted space that can occur from doubling.
  • That said, increasing by n may be too slow when many items are added to the array.
    • The repeated calls to the Resize/Reallocate method which runs slowly, O(n) time, is quite inefficient.

Psuedocode for ArrayLists

  if size == arr.length
    resize()

  arr[size] ← item
  size++

resize() { //doubling
  temp ← arr
  double ← size * 2
  for i → size
    temp[i] ← arr[i]
  arr ← temp
}

resize() { //increase by n
  temp ← arr
  capacity ← size + n
  for i → size
    temp[i] ← arr[i]
  arr ← temp
}
