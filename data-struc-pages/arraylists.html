Learning: Array Lists

What is an Array List?

First, we must understand what an array is. Arrays are a basic datastructure common in most programming languages. However, they are limited as for programming languages like Java and C/C++ where the size of an array is immultible (unchanging). This can often limit how arrays can be used. To still utilize the many strengths of arrays while allowing for the benefits of a dynamic data structure, Array Lists were created.

Array Lists make use of arrays as a data structure but allow for dynamic sizing. They are useful where there is no clear size limit to the number of elements that may be added.

How to make an ArrayList?

Variables

  • Array - this is where information will be stored
    • The type of this array should be the data type of the items you want to store
  • Size - this is the number of items that have been added to the array
    • This variable is also used to add items into the ArrayList

Methods

  • Add Item - add an item to the ArrayList using the Size variable as an index
  • Resize/Reallocate - when capacity is met, increase the size of the array
    • There are multiple methodologies on how size should be increased: increase capacity by n, double capacity, etc...

How to Deal with Resizing/Reallocating

Double Capacity:
Doubling can lead to a substantial amount of wasted space, espcially as the size of the array grows incredbily large

Increase Capacity by n:
Increase by n my be too slow when lots of elements are added to the array and many cause several calls to the Resize/Reallocate method, resulting in inefficency.

Psuedocode for ArrayLists

ArrayList {
  size ← 0
  arr ← new array[]
}

addItem(item) {
  if size == arr.length
    resize()

  arr[size] ← item
  size++
}

resize() { //doubling
  temp ← arr
  double ← size * 2
  for i → size
    temp[i] ← arr[i]
  arr ← temp
}

resize() { //increase by n
  temp ← arr
  capacity ← size + n
  for i → size
    temp[i] ← arr[i]
  arr ← temp
}
